文件往返验证

用一份合成 JSON，验证浏览器与“文件 / iCloud Drive”的手动传递。

只验证选中的测试文件

不读取游戏存档，不登录 iCloud，不自动访问目录。浏览器无法判断文件来自哪个云盘，也无法确认云端同步完成。

1. 当前浏览器能力

localhost 可作为安全上下文；手机访问普通 HTTP 局域网地址通常不可以。缺少增强选择器时，仍可尝试基础文件选择与下载。

2. 生成或读取测试文件

只接受本工具生成的 JSON，最大 16 KiB。选择器里的 iCloud Drive 由系统提供，请手动选择测试文件。读取不会改写原文件。

3. 导出新的测试副本

保存位置由浏览器或系统决定。Safari 可将下载位置设为 iCloud Drive，也可在支持时通过分享菜单“存储到文件”。增强另存为请保留随机新文件名；不选择已有文件。若浏览器提供“每次访问都允许”，本测试不需要，请仅允许这一次。

如何验证 iCloud 文件路径

  1. 生成新测试，导出到系统中可见的 iCloud Drive 测试位置。
  2. 重新“选择测试文件”，核对 probeId、revision 与 SHA-256。本页保存的比较基准只存在当前标签页内存中。
  3. 在另一台设备打开这个独立测试页，从该设备“文件 → iCloud Drive”选同一副本，人工核对相同 ID、revision 和完整 SHA-256。
  4. 可在第二台设备点击 revision +1 后另存新副本，再回第一台设备读取；原文件保持不变。

本机读回一致只能证明文件往返；第二设备读到相同内容才是跨设备到达的人工证据。下载发起、系统分享返回、文件写入完成都不等于 iCloud 同步完成。
