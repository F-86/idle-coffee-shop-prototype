## 新专项覆盖

- 标签、唯一ID、原生file input、file-selector-button、可见确认后果及默认闭合技术详情。
- 画质选中态、预览文件名、简明双卡、详细元数据、较早日期提醒、重选/取消/成功的焦点返回、生成后才出现下载/分享。
- 普通写入失败、坏档/冲突时恢复区自动展开；仍可导出真实原始档或有效当前副本。
- 离线金额严格使用已经提交的金库增量，包括到账为0但存在待收金额的样本；不展示销售额或在途现金作为收益。
- 显示时长向下取整到秒，59.999/60/61.999秒边界保持准确模拟；旧策略迁移、重复领取和取消原子性继续覆盖。
- 两柜台和经理的升级前后收益、报价、扣款、余额不足、重复输入及满级。

## 审查发现和修复

1. 普通写入/配额失败不会设置saveBlocked，不能仅靠该标志展开新的恢复折叠区。失败返回和异常分支现在主动展开恢复入口。
2. 刚导出的文件与本地档可有相同时间戳，而内存已经继续营业。日期告警不足以覆盖此回退，所以确认区始终明确“较早进度会回退”，不依赖可选旧日期或重复标记。
3. 预览区域增加可命名region；主动取消或成功导入后，焦点回到可见文件输入，避免留在隐藏操作上。
