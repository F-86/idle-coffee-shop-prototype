# Mac 独立方向验收提示

仅测试咖啡项目；不要操作其他项目，不合并main，不改部署配置。先确认当前工作区；有修改则使用独立worktree。不要猜历史Mac目录。

1. 在已指定仓库 F-86/idle-coffee-shop-prototype 正常 fetch 任务分支 codex/light-3d-coffee-slice，核验父任务提供的最终SHA。默认首页已是新3D游戏，旧版仅在Git历史。
2. 在该任务现用目录 npm ci，然后 node --check app.js、npm run typecheck、npm test、npm run build。Node24推荐；现有Node22.23可先跑，若不兼容报告实际错误，不随意改测试。
3. 独立测试origin：npm run dev -- --host 127.0.0.1 --port 4183；打开 http://127.0.0.1:4183/?qa=1，不复用日常档的端口。
4. 先保存真实截图：桌面1280×900、手机390×844、横屏844×390，注明浏览器/DPR、缩放100%。检查后墙菜单、木柜台、青/粉纵深队伍、方块人物、杯和现金、经理后通道。这是本轮首份实际像素证据。
5. 营业90秒，观察进入→排队→制作→交杯→带杯离店→台面钱→经理收走→金库到账。只读 window.__coffeeSliceDebug.readState() 可辅助精确分账本，不能调用业务函数替代UI。B+P+M+spend=1200+totalEarned；经理搬运不创造钱，B只在金库存入时上涨。
6. UI招客、换配方、买柜台升级、等待余额后升级经理。当前杯快照不被换配方/升级追改。A浓缩时间−25%，B拿铁杯价+12%。重复操作不得负余额/绕过冷却；Retina场景入口/菜单/等级牌命中正确对象。
7. 手机横拖不能误点升级；从画布纵滑能到卡片；主要按钮至少44px高。两张经营卡片都可操作。反复打开/关闭帮助，Escape有效。
8. 暂停20秒无进度，恢复不补暂停时间。刷新恢复；离开60秒回来只结算一次，再刷新不重复。第二标签页同origin保存后，旧页暂停提示，可导出当前分支/明确读取最新档，不合并余额。
9. 跳其他页面再Back/Forward，店面与唯一循环恢复，无死页/倍速。缓存/隐藏区间不得重复收益。记录控制台、网络真实错误。
10. 另用全新origin准备损坏/未来schema档：保留原字节、阻止自动覆盖、可导出；明确点击开始新店才先备份后重置，不碰正常档。

返回实际SHA、环境、每项PASS/FAIL/BLOCKED、真实桌面/手机截图和最短复现。云端核心/NullEngine测试不能代替shader、触控、BFCache和玩家路径。iCloud仍未配置，只能显示本地存档。
