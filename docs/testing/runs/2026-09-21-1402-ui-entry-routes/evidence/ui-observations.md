# UI 观察证据摘要

## 入口隔离

- 修复前：在 127.0.0.1:5173 的已有存档中，语义点击“查看一号柜台详情”实际触发了重叠的橙色升级牌；一号柜台由 Lv.1 变为 Lv.2，并出现升级 toast。
- 修复后：详情按钮矩形固定在柜台上半区，升级牌位于下半区。点击详情后可见“当前售价 / 当前倍率 / 升级后售价 / 升级后倍率 / 制作时长 / 升级后时长”；没有扣款或升级。
- 5174 独立新 origin 中，候客地毯点击前后“柜台待收”由 `¥8` 变为 `¥16`，出现 `⚡ 一号柜台已加急出杯，顾客拿到咖啡了。`；同时 `role=dialog` 数量为 0，证明没有串开详情。
- 真实 UI 升级一号柜台至 Lv.2、打开拿铁详情并点击“解锁 · ¥180”后，详情变为 Lv.1，升级预览变为 `¥14 / 3.1 秒`，余额按一次解锁扣款变化；打开选择器时拿铁选项为已解锁，选择后 aria-label 变为“选择一号柜台咖啡，当前蜂蜜拿铁”，待收保持不变。

## 视觉摘要

- 1280 桌面截图中可见固定顶部地点/余额/加速/营业/HUD，墙面咖啡菜单、后墙与设备、柜台前透视地毯、经理后场通道、左入口和右出口保持同一 2.5D world；咖啡墙摘要显示五个升级点，柜台升级牌显示金额。
