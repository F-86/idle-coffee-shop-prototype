## 问题与缺口

- 基线问题：横屏金库/一号柜台交叠，柜台高度不足；竖屏辅助 footer 视觉噪声较大。
- 修复内容：横屏柜台增至 108px、金库下移避让快捷入口和柜台、场景主要选择/升级/经营按钮补足 44px 触控高度；桌面柜台带左移；竖屏隐藏碎片化 footer，同时保留 world 横滑。
- 动态回归：营业按钮可切换并恢复；订单弹窗可打开且 Escape 关闭；竖屏横滑后 `scrollLeft` 从 0 到 `360` 再恢复；点击可负担升级后 一号柜台显示 `Lv. 2`；连续采样看到制作/经理收款状态变化和待收金额变化。
- 重载观察：一次 844×390 快速重载截图出现短暂的大色块中间态；等待 1400ms 后稳定为完整背景，重复复查未复现，未计为布局失败；仍建议未来把资源加载占位态纳入专门用例。
- 未执行：真实手机触控设备和读屏路径、正式 FX-UI fixture 定义、完整 M1–M3 业务规格回归。
- 不在本轮范围：经济公式、经理容量、离线边界、存档迁移和正式 Q1 数值。
