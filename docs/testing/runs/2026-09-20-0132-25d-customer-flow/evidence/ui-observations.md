# UI 观察证据

## 场景层级

- 正常桌面视口：`#sceneWorld` 与背景、React 场景控件、Phaser canvas 同属场景 world；入口锚点位于左侧，出口锚点位于右侧。
- 1280×800 截图中可见三块梯形地毯从各柜台前缘向前景展开，顾客站在地毯上；经理的推车/收款路线位于咖啡墙与柜台之间的后场带。
- 667×375 读数：world 约 `539.8×300.5`；Phaser 层与 world 同矩形；经理通道约位于 `y=115.7`、地毯从 `y=156.2` 向下展开，柜台操作带从 `y=123.2` 开始。
- 390×844 读数：场景 world 保持约 `820px` 的可横向浏览宽度；页面级 `scrollWidth - innerWidth = 0`，场景内部 viewport 可滚动；滚动到 `scrollLeft ≈ 524.6` 后，出口矩形进入可视区，入口离开可视区。

## 满位离店

- 当前只读快照：`queueCapacity = { counter1: 5, counter2: 4, counter3: 4 }`，对应队列长度为 `5/4/4`。
- 浏览器截图连续观察到“满位 · 离店”人物/标签在左侧入口附近出现，随后向右侧出口方向移动并淡出。
- 动画后只读快照仍为 `5/4/4`，没有为满位顾客增加队列；`managerMotion.lane = "back"`。

## 运行时

- 本轮浏览器 `warn/error` 日志为空。
- 测试使用真实页面截图、浏览器滚动和只读 DOM/CDP 读数，没有直接调用业务函数改变状态。
