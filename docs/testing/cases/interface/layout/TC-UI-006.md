# 方块人物清晰度与 2.5D 场景融合

## 目标与依据

验证咖啡师、顾客和经理在主场景中的轮廓清晰度与层级关系。规则：[REQ-UI-004](../../../../product/specs/interface.md)、[REQ-UI-006](../../../../product/specs/interface.md)，候选 v0.1；实现状态未知，本文件不是执行结果。

## 前置条件与参数

- 独立测试 origin，加载包含三柜台、顾客队列、咖啡师和经理的丰富场景。
- 参数实例：1280×800、844×390；另记录当前浏览器 devicePixelRatio。
- 只观察视觉，不用状态注入替代浏览器画面。

## 操作与预期

| 步骤 | AI 通过 UI 执行的操作 | 可观察预期 |
| --- | --- | --- |
| 1 | 观察桌面场景中的咖啡师、顾客和经理 | 方块边缘清楚，人物主色与动作可辨认；人物不出现明显 Canvas 平滑模糊，也不被背景灯光吞没；经理位于柜台与墙之间的后场通道。 |
| 2 | 切换到 844×390 横屏并观察顾客进出 | 小画布下人物仍保持硬边轮廓；顾客放大后不遮住柜台主操作、图标选择器或候客地毯容量反馈。 |
| 3 | 观察制作、取杯和经理收钱反馈 | 放大后的角色仍与各自世界坐标同步；顾客沿柜台前地毯向前移动，取杯后向右侧出口离店；动画不抖动、不瞬移、不产生额外控制台错误。 |

## 等待与通过条件

每个视口至少观察 3 秒并保存截图；控制台 warn/error 为空。全部断言满足才 PASS；只在单一屏幕截图中可见但无法复现的差异记录为待设备验证。
