# TC-3D-015 可选真实帧节奏诊断

辅助 REQ-3D-024；计划见 [performance-measurement](../../plans/performance-measurement.md)。

## 自动独立用例

1. 已知递增单调时间戳：首样本无FPS；FPS、nearest-rank p50/p95/max、严格>50/>100ms及累计值与独立算术一致。重复/倒退/NaN/Infinity不能制造帧或破坏参照。
2. 10秒窗口淘汰旧间隔但累计长间隔保留；前台20秒停顿完整保留；重置后后台间隔不计入。
3. 100000次写入后仍只有两个4096元素数组，实例不变；未覆盖时不误报截断，被覆盖端点仍在窗口才报截断，移出窗口恢复。
4. 默认/非精确qa参数没有性能panel/debug。qa=1默认折叠，零采样/场景统计读取；展开601次10ms tick只更新7次DOM/上下文，不增加RAF/timer，不改变核心/保存状态。
5. 120Hz下省电仅记录30fps实际提交的帧；隐藏、可见失焦、BFCache、模式、canvas/window/visualviewport尺寸、读取存档均清除旧段。WebGL对象存在但contextlost也不得报告有效FPS，恢复另起新段。
6. 冻结读数和上下文稳定、重复冻结不累加文本；重启只重置诊断。renderer初始化失败显示BLOCKED而非虚构FPS。
7. 折叠Route QA不查询模型位置、不更新快照/DOM，隐藏marker；事件历史仍保留，重开刷新。清理后所有新增DOM/监听移除。

上述时钟由测试代码明确模拟，只验计算和生命周期，不证明真实WebGL帧率。真实Mac必须按计划完成四个前台60秒段及单独后台/焦点检查，并记录实际值。
