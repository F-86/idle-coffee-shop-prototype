# TC-3D-001 · 经营与资产转移

- ID: TC-3D-001
- 需求: [light-3d-slice v0.1](../../../product/specs/light-3d-slice.md), REQ-3D-002
- 优先级: P0
- 类型: 核心/持久化 + 集成
- 标签: slice, original-3d
- 规格状态: accepted 行为；经济精确调参 draft
- 目标: 经营与资产转移符合本轮闭环。
- Fixture/前置: 零存档、开始营业，选择两种咖啡。
- 数据: 固定初始seed；金额分，时间秒，UI咖啡币=100分。持久化用独立origin/key，不影响旧版。
- 步骤: 通过 UI 观察一位客人从入口排队到出杯。逐段读取只读状态，记录 B/P/M。
- 逐步预期/通过条件: 出杯只增加台面钱；经理收走只改变 P/M；回金库只改变 M/B，A=B+P+M 不因搬运变化。
- 超时: 最长 90 秒，须至少一次完整存入。
- 证据: 命令/断言输出；UI前后截图与只读状态（可获取时）。核心测试不可代替UI通过。
- 清理: 销毁独立实例/浏览器上下文，清除只属本用例的临时档。
- 待决策: 正式经济平衡、原生包装、真实CloudKit账号配置均不在本轮验收。
