# TC-3D-012 清晰画布与固定步连续呈现

关联REQ-3D-024；基线4df0442；核心经济/经营规则与渲染解耦。

- 给30/60/90/120/144/240Hz每种10秒输入。默认提交每个RAF、时间间隔相等；平衡/省电在屏幕能力范围内最多60/30次每秒。核心累计10秒，慢帧只提交一次，无补帧突发。
- 在30fps跳过的10ms后切默认，下一RAF结算完整可见16ms，不多/少推进；相同时间RAF/非法时间不再推进；隐藏/重复pageshow沿用既有时间幂等用例。
- 经理直线在预热50ms后每显示帧位移=2.6/hz；进入中的顾客=2.5/hz，无20Hz冻结帧或帧率相关拖尾。验证30–240Hz，慢帧使用最后两步，不能横穿多个转角。
- 每种画质以144Hz输入30秒，与参考核心advance(30)的快照和事件精确相同。取样不改变任何核心字段。
- 暂停多次取样位置不动；离线结算和换档后重置。新客ID与出生点匹配，杯子和阶段同步，完成的同一杯不会同时在机台与手上。
- 1280×900@DPR2默认2、平衡1.5、省电1；横竖手机、1080p/4K符合各模式像素上限，CSS画布尺寸/拾取坐标不变。最高负载不超预算，不能将该算术称为清晰像素验收。
- 切换模式同步可见按钮、aria-pressed和独立偏好；连续相同选择无第二循环。偏好读写失败不破坏游戏档；即时生效但持久化失败有提示。
- NullEngine每次实际render都有一对beginFrame/endFrame；模式切换不重建场景。回归实体拾取、关闭/重开/键盘、静态阴影和移动节点、升级与角色释放。
