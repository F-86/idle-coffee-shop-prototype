# TC-3D-023 咖啡独立升级与柜台双入口

版本2.0；REQ-3D-033。参数draft，测功能正确性，不测平衡结论。

- A：A/B左选择右升级，实体区域分离、44px、不重叠；柜体无操作，遮挡和跨目标抬手安全。
- B：recipe-panel只选咖啡，counter-panel只升级柜台，coffee-panel只升配方；面板路由、选中、重复输入、关闭/重开/延迟close、键盘、背景拦截和隐藏操作限制。
- C：墙牌数值/等级跟随对应咖啡，另一配方或无变化帧不重绘；咖啡基础当前/下级数值、费用、等级、余额不足及满级；选择卡显示当前柜台真实实际值，柜台升级quote包含配方等级和专长。
- D：两配方独立升级，同配方影响两柜台，资金与spend守恒，非法配方/不足/满级不变；连续购买用新等级费用。
- E：在制杯保持recipe/price/duration/elapsed；下一杯采用升级后数据；切换配方与升级不改变顾客队列或重复结算。在线/离线复用同核心结果。
- F：经济1旧档归一为经济2、两种Lv1；旧杯快照保留；新档保存/载入/同步替身CAS重试保留等级。非法/缺失/未来版本保护原档。
- G：portable v1原始校验/摘要后迁移、v2导出/解析/预览/确认/备份往返等级完整；混搭版本/错误等级/伪造摘要拒绝，旧客户端真实校验拒绝v2。
- H：全部恢复、离线80%、取消/失败/冲突、备份和文件异步竞态回归；Mac/移动/Safari像素与原生输入另列NOT_RUN或实际证据。
