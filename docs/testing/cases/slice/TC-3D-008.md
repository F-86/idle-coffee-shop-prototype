# TC-3D-008：真实实体操作与金额唯一HUD

对应REQ-3D-013/014/015。基线fce3e7c及真实Mac三尺寸截图。独立预期来自用户反馈，不能用实现反推验收。测试origin须独立，不污染日常存档。

1. 默认全屏页永久HTML只有¥金额HUD；没有worldanchor DOM按钮、暂停/设置HUD、进度悬浮条或台面悬浮金额。场景填充viewport，没有网页框。
2. 咖啡墙、金库、营业/设置物件、两柜台配方/升级牌、入口和经理是3D实体。文字随实体面透视缩短/光照，有正常深度遮挡，不屏幕朝向/顶层显示。
3. 聚焦每个入口，在1280×900、390×844、844×390及DPR1/1.75下，实际几何投影可点、至少44px高/宽，不靠屏幕card扩大目标。墙牌无不合理灯具遮挡。若真实屏幕字体仍太小或难辨认，方向FAIL，不因结构测试通过而接受。
4. 实体短按→对应动作一次；按下后移开9px以上、800ms长按、取消、二指、capture loss、不同目标抬起不触发。人物/家具挡住后，点遮挡前方不能触发背后实体。
5. 相机受限平移且角度固定，三个viewport边角仍在室内；所有入口可拖到。桌面/横屏初始构图合理，竖屏大柜台局部逛店，不缩成小岛。
6. canvas键盘焦点，左右选实体，上下平移，Home回柜台A，Enter/空格激活；重复激活按键不交易。临时物件名可辅助，不能常驻多HUD。弹窗可见焦点、切换、关闭×/背景/Escape恢复canvas；背景inert。
7. 两柜台、两配方、一经理完整90秒链仍可玩。换配方/升级、暂停/刷新、离线、坏档/冲突保护不变。Back/Forward/销毁不会重复RAF/监听/收益或晚回调。
8. 3张真实完整viewport截图 + 菜单/柜台/营业/设置的点击和关闭后证据。记录实际SHA、browser、DPR、canvas rect、真实时间。CPU/NullEngine/handler结果与真实浏览器PASS/FAIL/BLOCKED分别列明。
