# TC-3D-007 · 全屏店面与内嵌操作

- ID: TC-3D-007
- 需求: [light-3d-slice](../../../product/specs/light-3d-slice.md)，REQ-3D-009/010/011/012
- 状态: accepted；用户2026-10-03看实际截图后的明确反馈
- 优先级: P0
- 类型: 界面/镜头/输入/弹窗
- Fixture: 独立测试origin；1280×900、390×844、844×390，DPR1和1.75；初始店铺或合法恢复档。
- 目标: 整个可用屏幕是一间可逛的咖啡店，而非网页内缩小画布与下方经营面板。
- 数据: 全screen CSS viewport，金额分；44px最小触控高度；固定摄影角度可平移。
- 步骤/预期:
  1. 打开默认首页，不滚动。canvas边界覆盖viewport，无页边距、常驻经营卡片/侧栏/网页页头；HUD不挤占场景高度。
  2. 检查初始镜头与三种尺寸截图。柜台能看见并操作；房间地面/墙体延伸填满背景，不存在置中小地台与大片纯背景。
  3. 拖动到墙面咖啡牌、墙上金库、柜台配方牌/升级牌、入口和经理。HTML触控控件与物件的worldanchor对齐，DPR和缩放不重复变换；被裁到边缘的控件不可点，逛店导航能回到完整目标。
  4. 点墙上咖啡牌查看/分配；点柜台牌选配方/升级；点金库查看待收/运送钱；点经理升级。仅出现当前操作窗口，关闭×、Escape、点击背景都回店，点窗口内部空白不误关；窗口遮挡时背景不得交易/拖动。
  5. 连续拖动、长按、取消/次指针不得变成点击。窗口内滚动不得移动店铺；touchsafe-area、地址栏收起/展开与旋转后仍满屏且命中一致。
- 通过条件: 以上真实UI断言全部满足；CPU投影/源代码测试不能替代像素与触控通过。
- 超时: 每项条件30秒，营业闭环90秒。
- 证据: 三种尺寸未滚动的真实scene-fill截图；弹窗与关闭后的前后截图；只读readAnchors/状态辅助；Node测试输出。
- 清理: 只清理本测试origin数据/独立上下文，不动日常档。
- 待决策: 本次不新增配方解锁经济、研发、真实CloudKit或原生App。
