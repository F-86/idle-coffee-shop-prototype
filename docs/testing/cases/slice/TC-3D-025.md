对应 REQ-3D-035 / LAYOUT-1.0。代码、测试计划、执行结果分别维护。

- 在全新小店打开装修；观察停止新入店、现客连续完成、经理回库；只有安全清场后可编辑。
- 选 A，移动一格/旋转，检查实体和两块操作牌跟随；把占地放到 B 或入口应红色且无法完成；取消后原布局及余额不变。
- 添置桌椅，合法摆放后完成，确认只扣一次费用；新顾客取杯后选座，坐完离开，金库不因起身多一笔收入；全占满时客人外带。
- 再打开装修，收起/恢复家具不退钱、不丢等级和柜台资产；最后一个柜台不可收起。
- 满足阶段与余额后扩建一次，在新增区域放柜台和桌椅；旧区域与新区域都能到达，经理实际收钱。
- 刷新、导出/导入后布局、扩建、座位占用与钱一致；离线按相同布局80%推进，不多领。
- 编辑时隐藏页面或发生跨窗口冲突，未提交修改丢弃，未改变玩家原暂停标记；存储失败保留恢复路径。
- 反复编辑/取消/旋转/收起/恢复，检查无重复监听、资源泄漏或点击旧物件；手机托盘可滚动且保留场景操作空间。
