# TC-3D-024 简洁设置与首次开店引导

关联 REQ-3D-034；版本 SETTINGS-QA-1.0；基线 cc99591。与 TC-3D-019/020/021/022/023 保持回归，覆盖优先行为而非经济调参。

| 用例 | 前提与操作 | 独立预期 |
|---|---|---|
| 01 两入口 | 打开设置，展开/收回画面，打开/返回存档 | 只有画面+存档；原四档与偏好保持；保存操作只在存档内 |
| 02 自动保存失败 | 合成写失败→自动保存→设置→存档→导出→恢复写入重试 | 入口有提示；恢复卡可见；原已保存字节不变；副本等于有效现场；重试成功后消失 |
| 03 受保护原档 | 坏档/未来档打开存档，下载原始档，取消/确认新店 | 原始字节完整；无占位当前副本；取消不改；确认且备份成功才开始 |
| 04 读取/缺失 | 有效店后读取失败或源缺失，导出现场/重试 | 冻结不自解锁；原/当前按可用性呈现；缺失需显式新店 |
| 05 打开时冲突 | 存档已开时接收storage冲突 | 恢复卡立刻出现，普通保存/生成立即禁用，读取入口可达 |
| 06 四步初见 | 确认无档的首次启动，逐步下一步 | 非模态四步对应左牌/右牌/墙牌/金库；自动经营与无引导对照相同；仅写独立标记 |
| 07 一次性 | 跳过、完成、中途刷新（包括首个自动保存前） | 不自动重复；反复点击结束按钮不改状态 |
| 08 已有店 | 初始数值档、发展档、旧版档、暂停档、导入档启动 | 全部无强制新人引导；不凭金币/等级判新手 |
| 09 偏好故障 | 只拒绝引导标记读取/写入；另测全存储失败/WebGL失败 | 前两者不弹引导且自动保存继续；后两者保留原保护/报错，不假装教程可用 |
| 10 中断与焦点 | 引导中打开/关闭设置和场景面板、Escape/异步close | 同步骤恢复；操作背景不误点；焦点不返回隐藏祖先里的按钮；无全局keydown |
| 11 离线/BFCache | 引导中hidden35秒→结算→关闭结果，再跳过/BFCache | 收益/暂停/保存与无引导对照一致，只有一次领取；教程不阻挡结果或重播 |
| 12 导入/替换 | 新店教程中取消文件导入，然后确认导入；另测跨窗最新档 | 取消保留步骤；成功替换结束旧教程，之后刷新不重启 |
| 13 播报与销毁 | 当前步骤连续推进多帧，hidden首次启动，销毁后重复点击 | 稳定步骤不重复写aria-live内容；后台无模态；销毁无残留监听/步骤推进 |

自动化见 tests/fullscreen-ui.test.mjs 中 TC-3D-024（17条，包含复用的恢复回归）。真实像素、原生键盘、屏幕阅读器、系统文件选择器必须按计划独立验收。
