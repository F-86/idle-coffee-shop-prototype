# TC-3D-029 装修操作行响应式回归

需求：REQ-3D-039；继续验证 TC-3D-025～027 的草稿、取消和暂停语义。

前置：隔离浏览器测试档；CSS zoom 为 1，不使用用户日常存档。初始视口 1180×757，暂停并清场后打开家具面板。

1. 「取消」与「完成布置」水平显示完整文字；完成按钮至少 100px 宽，不能按汉字逐行断开。标题、费用与按钮组不重叠。
2. 无需纵向滚动即可看到默认桌面目录及移动、旋转、收起按钮。目录图片仍清楚可辨，横向滚动/拖拽方式不变。
3. 检查 1440×960、390×844、320×568、844×390。空间不够时完成/取消作为整体换行，文字不拆开；移动控制可换行，面板不出现横向溢出。极窄或矮屏允许纵向滚动，所有控制仍可到达。
4. 免费重新摆放及有购买费用时分别检查标题区。无效布局和拖拽中完成仍禁用；取消不扣款，合法完成只扣一次且保持暂停，再次点击不能重复购买。
5. 鼠标/触摸拖拽、WebGL 场景、屏幕尺寸或浏览器无法验证的项目分别标记 BLOCKED/NOT_RUN，不能由 CSS/模拟 DOM 测试替代。

自动化契约覆盖按钮宽度/不收缩/不换字、按钮组换行、紧凑图片及控制组换行。真实几何和可读性必须由浏览器截图与边界测量复核。
