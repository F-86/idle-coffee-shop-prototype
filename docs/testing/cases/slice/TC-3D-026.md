# TC-3D-026 底栏目录和指针装修

对应REQ-3D-036 / LAYOUT-2.0。

- 打开装修等待安全清场。确认底栏包含现有A/B柜台、两种咖啡、可购柜台/桌椅；分类与收纳结果正确，退出即隐藏。
- 从“新桌椅”按住拖向空地；移动时格子预览绿/红和原因同步；松手只进草稿，完成才扣一次。拖后click/双击完成不重复购买。
- 拖到柜台内部、入口、店外、未解锁区域和底栏内释放；每次应回到原草稿且不扣款。
- 直接拖动A柜台，旋转、收起、放回，保留等级/配方和抓取相对位置。空地拖动镜头不误移动家具。最后一个柜台不可收起。
- 拖动浓缩或拿铁墙牌：离墙、墙位非法或重叠为红；合法墙位完整移动框、挂件和内容。收起后制作配方/等级保留；从收纳取回同一块。
- 拖到一半Escape、窗口失焦、pointercancel或捕获丢失，当前移动取消且鼠标不粘住。再次Escape/取消退出整次装修。隐藏/刷新/跨窗口冲突不保存草稿。
- 触屏横滑卡片浏览不买物件；纵向拉出可摆放；抬起后再拖动不能沿用上次捕获。另用键盘选卡、方向按钮、旋转与收起完成相同操作。
- 初始旧布局和编辑后都无地毯/路线箭头，客人和经理依旧沿真实模拟路径经营。
- 旧布局1在途档读取/离线/导出仍保留所有资产/位置；新布局2墙牌往返一致，坏牌和未来版本不覆盖原档。

自动化、真实浏览器及设备结果分别见 runs/2026-10-05-renovation-drag/；安全布局/核心测试不能代替真实像素与触控证据。
