# TC-3D-022 游戏面板

版本1.0；关联REQ-3D-032。只改变UI和信息层级，数据、资产、配方快照、冲突与离线保护是独立不变量。

- A：四类面板统一结构；44px操作、唯一ID、原生输入及标签、焦点与描述、选中画质状态；检查 1440×900、390×844、320×640 和 844×390 不横向裁切。
- B：柜台/经理当前与下一级数据来自真实quote；余额不足、足够、购买后重复点击、满级不产生虚构收益；折叠说明不遮蔽价格和主操作。
- C：文件选择是可见原生输入，样式无伪拖放或异步文件选择触发；生成后才显示下载/分享；预览文件名、简明对比、闭合详情中的身份/校验/账本；旧日期与重复警告。
- D：未勾选不能确认；后果文字在折叠区外；取消、Escape、返回、重选、隐藏、异步乱序、备份失败/冲突/坏档保护继续执行TC-3D-021，不简化为仅检查按钮存在。
- E：恢复失败/缺失/冲突时自动打开恢复区，原始档与有效当前副本仍各自可导出；正常面板无需展开技术恢复说明。
- F：离线结果只显示真实离开时长和实际已提交钱包增量；构造 generatedAmount ≠ amount 的情况，验证展示来自 amount。原模拟精度及旧策略迁移断言不变。零到账、分秒边界、取消/失败/重试继续覆盖；没有技术细分或同金额toast。

真实原生文件选择器、手机和像素验收单列，不能用模拟DOM代替。
