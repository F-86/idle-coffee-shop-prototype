# TC-3D-027 双门经营与暂停装修

需求：REQ-3D-037、038、039。

前置：隔离 origin、新店及 QA 合成档；所有数字保持 draft，禁止在日常档测试。

1. 新店顾客从右入口进，完成取杯/堂食从左出口离开；交杯余额和累计营业额各增加同一份杯价，离店不再入账。场景没有经理、推车、金库、咖啡墙牌。
2. 营业时点家具，仅提示先暂停；点暂停立即停止新客，已有客正常完成。等清场后草稿可以移动家具。
3. 添加桌椅，未完成不扣钱。点击恢复提示先完成/取消且保留草稿；完成一次扣一次，仍暂停。取消/关闭/刷新未提交内容不扣款。明确恢复才接新客。
4. 保存暂停档，离开/刷新/导入，余额不因关闭期间增加，状态不自动恢复。在线清场产生的旧单收入仍正常。
5. 旧待收和携带现金转钱包一次；历史营业额/经理支出/咖啡等级/家具身份不变。反复加载及文件导入不重复发钱。旧在途路线能收尾；新出口阻挡的家具只收纳/安全调整，并有需确认的说明。
6. 底部图标栏紧凑、有真实本地图片，仅咖啡/背景/家具/招客；咖啡面板两个配方可切换升级；三种背景免费改变店外配色，刷新保持。
7. 装修最大880px、四周留白；目录每件物品有图，拖放/旋转/收纳支持；非法与重复输入不提交，触摸横滑不添置。
8. 存档冲突、取消离线结算、文件预览冻结经营但不改用户暂停设置；保护原始字节，恢复只恢复合法保存状态。

证据等级：核心/模拟 DOM/NullEngine 分开标记，不作为真实视觉/原生输入通过。执行结果见同名计划与对应 runs 目录。
