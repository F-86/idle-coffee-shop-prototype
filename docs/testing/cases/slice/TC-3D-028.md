# TC-3D-028：手动原料闭环

需求：REQ-3D-040–042。

前置：独立测试存储，当前经济5，初始40豆/20奶；不得操作用户日常存档。涉及旧档的用例使用冻结合成夹具。

1. 将两柜台置于待制作且共享最后一豆，推进一步：只开始一杯，另一位客人空手走出口；缺奶拿铁不能损失豆。
2. 在制作中升级和切配方、每步保存/重载：原杯价/时间/配方不变，库存不再扣。
3. 用完库存，暂停营业并请求装修：在制杯完成，未制作客离开，清场进入可装修状态。
4. 购买一份、一批、补满；检验实际数量、容量、支出与净钱包。连续点击不能超容量或借款，余额不足整体拒绝。
5. 保持暂停购买；离线候选/文件预览/保护状态阻止购买。报价改变必须先显示新量价。
6. 对同一快照分别在线推进T×0.8和离线T：除了结算标识，库存、现金、顾客、时钟一致；缺料后无采购/自动赠送。
7. 旧经济1–4每种有效档迁移：初始库存只发一次，已有杯不扣；旧未结区间按旧策略完成，再原子切新策略。
8. 当前5缺库存、越界库存、仅改版本标签造成字段不匹配、旧离线策略不匹配：拒绝并保留字节。取消/失败/重复结算不产生资产。
9. 文件5导出/导入保留库存，重复导入不叠加，旧文件迁移后可导出新文件；导入前备份保留旧库存。
10. 浏览器窄屏检查五图标、购买卡、可购禁用、手动暂停、离线净余额与缺料提示；空豆且买不起的风险提示清楚。

通过：自动化与浏览器结果分别记录，不把模拟DOM/NullEngine当像素或真实输入证明。
