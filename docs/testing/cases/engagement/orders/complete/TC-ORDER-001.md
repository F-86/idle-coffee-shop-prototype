# 点击候客地毯催制作并只交付一次

## 目标与依据

验证本标题行为。规则：[REQ-PROD-001](../../../../../product/specs/operation.md)、[REQ-PROD-002](../../../../../product/specs/operation.md)，候选 v0.1；测试数值以 [Q1](../../../../../product/parameters.md) 为依据。实现状态未知，本文件不是执行结果。

## 前置条件与参数

- 独立初始化：Q1 一号柜台已解锁、有咖啡师和可服务顾客；在制杯已推进 2 秒；记录点击前 B/P/M 与 brew 状态。
- 参数实例：生产中点击；同一制作实例重复点击。每个分号分隔项独立准备；逗号枚举也逐项执行。
- fixture：FX-PRODUCTION，准备与能力要求见 [共享手册](../../../../shared/fixtures.md)。
- 全程记录 B/P/M，除明确要观察的生产外隔离其他收支；禁止用被测业务函数算预期。

## 操作与预期

| 步骤 | AI 通过 UI 执行的操作 | 可观察预期 |
| --- | --- | --- |
| 1 | 在制杯进行到中途时点击已解锁柜台前方候客地毯一次 | 当前 brew 立即完成，队首顾客取杯，P 增加该杯快照价格；下一杯自动制作并从 0 开始。 |
| 2 | 观察到下一杯已从 0% 开始后再次点击同一地毯 | 第二次点击只完成新的 brew id；两次点击各最多交付一杯，不创建订单序列，也不重复结算同一个 brew id。点击柜台实体区域只打开详情，不改变生产。 |

普通 UI 状态变化最长观察 10 秒；保存要求 1 秒。明确标注的生产/离线/持续运行时长优先，观察窗口可在目标时刻后延长 2 秒用于采样，但业务计算区间不能随之延长。时间容差与证据方法见共享手册。

全部断言满足才 PASS；候选基线运行须在报告标明“候选差距测试”。数据或观察能力不足记 BLOCKED，不把当前实现行为替换为预期。功能缺失记 FAIL/相对候选未实现，是否正式产品缺陷取决于基线确认状态。
