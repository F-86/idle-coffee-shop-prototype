## 操作与预期

| 步骤 | AI 通过 UI 执行的操作 | 可观察预期 |
| --- | --- | --- |
| 1 | 合法购买一次升级，等待保存信号最长1秒，再刷新 | 保存字段恢复，余额无重复扣款；在制杯不会凭空完成，经理载款可等值恢复，A 守恒。 |
| 2 | 在经理携款阶段再刷新一次 | P/M/B 与刷新前的位置语义一致；重新经营后该笔现金只入库一次。 |
| 3 | 再次刷新并核对字段清单 | 等级、员工、选择、地点、营业、奖励、加速时刻、引导、在制杯快照和经理运输字段均与保存快照一致。 |
