# 清晰度与连续运动修订计划

2026-10-04 UTC；基线4df0442；REQ-3D-024；TC-3D-012。用户实际反馈上一版仍卡顿、且模糊。

先区分三个问题：显示RAF限速、20Hz确定性核心位置台阶、画布采样不足。不能仅提高帧数或者再次降低画质作为修复。

1. 独立时钟：30/60/90/120/144/240Hz。默认每RAF一次，恒定delta；平衡/省电显式选择60/30fps上限，丢显示帧但不丢核心时间。质量切换、重复RAF、慢帧、隐藏/BFCache的可见尾部只结算一次。
2. 位置：默认核心仍0.05秒固定步；只复制最后相邻两步，按未消费小数步插值。经理、推车、顾客以恒定显示步移动；转弯不跨多个路段做大跨度直线，停靠不超越端点。核心状态/事件与未插值参考完全相同。暂停冻结，隐藏/离线/换档重置历史。
3. 离散状态：杯子、阶段、现金、顾客ID使用同一延迟快照；新客从自己出生点出现，离开后释放；配方/升级/钱不被插值创造。制作进度只在同一杯内插值。
4. 清晰度：默认DPR≤2/800万像素（1280×900@2为2560×1800），平衡1.5/450万，省电1/200万。字牌仍实体光照与深度，保持原高分辨率字图，启用mipmap/三线性和8×各向异性以减少斜面闪烁；只在文字变化时重画。
5. 模式设置在原设置窗口，显示选择与耗电取舍，保存独立偏好，不修改游戏存档。坏偏好/禁止读取用默认，禁止写入仍本次生效。模式切换不重建场景/第二RAF/重置游戏。
6. 保留静态家具阴影、冻结几何、值变更才更新字牌；Babylon beginFrame/endFrame与每个实际绘制配对。类型/语法/全测试/两种生产build/独立审查后正常推任务分支。

真实浏览器验收：相同设备/窗口/缩放、三尺寸和Retina屏；各模式运行至少30秒，记录实际帧间隔分布、长帧、拖动响应、字牌截图；冷热启动各一次；30秒内连续切换/关闭/重开设置、后台恢复、每柜台接杯和经理停靠。新默认提高采样/绘制次数，不能由单元测试推导“更凉”或“实际GPU更快”。云机WebGL不支持时记BLOCKED，真实Mac帧时/功耗/温度记NOT_RUN。
