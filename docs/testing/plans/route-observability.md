# 路线验收诊断计划

2026-10-04 UTC；TC-3D-014；辅助验证 REQ-3D-020 / REQ-3D-025，不新增经营规则。

1. 默认无面板、标记或全局调试对象；只有明确 `?qa=1` 启用。裸 `?qa` 和 `?qa=0` 不启用。普通 HUD 继续只有 ¥ 与设置。
2. 全部轨迹事实在 core 实际转移处发出，不从低频 DOM 采样推断：出生、各路线段/阶段、中心线交叉、实际终点删除。时间为模拟秒，同步发生的转移按独立序号保序；不得增加持久化 eventSequence。
3. 经理实际收款/存款带原目标、数量、相关余额前后值。A→金库路过 B 单独记 passage；空停靠无 collected。旧档尚未完成的一轮仍忠实记原次序。
4. 单顾客选择固定 ID；A/B/下一位只改变诊断选择。core、插值输入、实际同 ID mesh 位置分列，最后半步的 core absent / mesh present 合法。视口外、mesh 删除、WebGL 不可用分别显示。
5. 本地总事件最多128，所选顾客及经理各16；所选终点单独保留直到换人/会话重置。无网络、localStorage、独立 RAF 或计时器。页面恢复/离线跳跃、读档和新店开始新会话，防止旧 ID 误关联；离线模拟不伪装可视过程。
6. 同一输入在无观察者、真实记录器、改写接收对象/抛错的观察者间完整状态与业务事件逐字段一致；暂停/离线/保存/恢复不变。整段90秒、20Hz、144Hz获得同一轨迹事实。
7. 真实验收用独立测试 origin 或独立浏览器存储。QA 参数不创建测试存档，也不隔离原存档；不得直接在日常存档上做破坏性准备。真实像素验收仍必须逐人观察，不能仅凭面板宣称无遮挡、无穿模或完成视觉验收。
