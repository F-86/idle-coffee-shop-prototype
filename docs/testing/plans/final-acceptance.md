# 最终产品验收计划框架

状态：draft；这是一份范围清单，不是可执行计划。

最终验收覆盖 [功能地图](../../product/README.md) 中所有已确认功能：进入与引导、自动经营、经济结算、升级成长、员工与分店、离线、存档恢复、界面可用性。未确认系统明确列为待决策或排除，不默认为交付承诺。

准备正式计划时：

1. 固定产品规格版本，逐需求检查 [覆盖矩阵](../coverage.md)。
2. 引用确切用例文件，列出参数和设备矩阵，标记必选实例。
3. 包含正常、边界、异常、恢复和长时间经营场景；补充跨模块经营闭环。
4. 固定数值规则、时间预算、初始数据、版本与可观察证据。
5. 使用 [计划模板](../templates/test-plan.md) 和统一验收门槛，记录任何范围例外及来源。

当前仅有四条示例用例，远未构成最终验收覆盖。原型已实现列表和历史设计截图不能代替上述准备。
