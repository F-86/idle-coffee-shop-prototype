# 装修按钮布局回归计划

关联 REQ-3D-039、TC-3D-029。基线为 60e4c465f64dff4990875db27fb4afc4f55ff8ae。

## 已确认缺陷

公开 Pages 页面在云 Chrome、1180×757、CSS zoom 1 下，完成按钮为 72.390625×100px，四个汉字纵向排列。取消按钮继承全宽对话框样式，操作组和完成按钮允许收缩；目录之后的移动控制落在纵向折叠区。

## 修复边界

- 完成/取消保持自然宽度与完整文字；操作组不收缩，窄屏可整体换行。
- 缩小目录图片高度，给移动控制更多可见空间；极窄屏控制组可折行。
- 仅修改装修相关 CSS；不改草稿、禁用态、确认、消费、暂停、存档或部署配置。

## 验证顺序

1. 新增 CSS/DOM 契约测试，确认在基线上失败、修复后通过。
2. JavaScript 语法、应用与文件探针类型检查、全部核心/模拟 DOM/NullEngine 测试、探针测试、根路径/Pages/探针构建、空白检查。
3. 独立代码审查。发布功能分支后，由发布任务使用现有 Pages 流程合入与部署。
4. 公开 URL 重新执行 TC-3D-029，记录截图、完成按钮尺寸、scrollWidth/clientWidth 和移动控制边界。没有真实像素证据前不宣称 UI 已验收；WebGL 受限不能用安全绕过或模拟渲染冒充通过。
