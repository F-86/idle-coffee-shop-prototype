# 手动文件存档 QA 计划

版本 PORTABLE-QA-1.0；2026-10-05 UTC；REQ-3D-031 / TC-3D-021；对应 [规格](../../product/specs/portable-save-files.md)。基线59c7799，任务分支codex/portable-save-files。此计划只使用合成进度、独立origin和独立测试目录，不读取或替换日常真实档。

## 自动化门槛

1. 独立构造协议及散列样本，不以生成器输出作为唯一预期。文件大小前/后检查，未知format/schema/经济/离线策略、数值溢出/NaN等价JSON、错误账本/摘要、深层结构、篡改状态/元数据、缺失校验码、摘要重排/内容变化、正确Unicode字节。
2. 原始+内存备份、备份写失败/读失败/字节不符、备份期间别的写者、替换拒绝/落盘后读回失败、不确定时写屏障、读取恢复，保持无自动回滚。独立验证旧档身份迁移、普通保存修订递增、导入新身份、非倒退本地锚点，文件过去/未来时间都不领文件期间离线收益。
3. 实际main.ts handler：生成前台尾部/保存失败不生成旧档，输入只读/未确认不变，close/Escape/cancel/新文件/迟到读取或散列/隐藏/BFCache/销毁/存储事件，重复确认、重复同文件提示、导入后原始及可恢复备份，分享取消不下载、无分享API走下载，文件名唯一。
4. node --check app.js、npm run typecheck、npm test、npm run build；既有Pages base路径构建、git diff --check。独立安全/资金审查；不把localStorage称为事务性原子CAS。

## Mac 合成文件验收（待独立任务执行）

1. 在单独目录检出本任务确切commit，记录Node/浏览器版本、构建命令和源码指纹；独立新端口origin，确认不是日常档。只创建新合成店，不注入或读取真实用户档。
2. 经营至与新店明显不同，生成文件；记录UI保存时间/saveId/revision/余额/杯数，与下载JSON及SHA256核对。再次下载必须是新文件名，原文件仍保持字节不变。
3. 当前店继续营业形成差异，选择旧文件：预览展示差异；确认禁用直到勾选关闭其他窗口。先取消/Close/Escape，当前状态保持；再重新选择并确认，资产替换等于文件状态，导入身份新建，导出到导入间隔不发收益。马上重新读取不会二次领取该间隔。
4. 导出导入前有效副本，再选择该文件预览确认，可以找回导入前进度；原始副本单独导出且字节保持。故障/竞争只在独立合成origin由单独测试用例注入，不触碰日常档。
5. Mac Chrome及Safari分别执行；检查原生文件选择、下载、分享可用性与取消，键盘焦点、对话框滚动、390×844等窄屏。每个浏览器单独记录PASS/FAIL/BLOCKED/NOT_RUN。

## iPhone / iCloud Drive 手动往返（需用户明确指定测试目录）

1. 仅测试上述合成文件。Mac系统文件面板手动选择测试目录，记录文件名/字节数/散列；不要自动覆盖、目录授权或登录真实账户。
2. iPhone Safari加载同一代码版本，选择已到达的合成文件，只预览/确认合成店。记录新本地身份与资产；在iPhone生成新的文件，保留先前副本。
3. Mac收到新文件后再读取校验，核对精确字节和状态。这是人工双向文件交换证据，不能标为自动云存档或后台同步通过。
4. 只看到下载/分享成功不算iCloud到达；单设备打开不算双设备到达。文件未出现、分享入口缺失或来源版本不明分别记BLOCKED，不能推断原因。

## 停止条件

任一备份失败仍覆盖、未确认改档、资产加钱/合并、文件时间重复领收益、过期异步覆盖、未知文件被接收，均立即停止发布。真实浏览器门槛未完成时只交任务分支，不更改main或部署。
