# 公共准备流程与数据契约

## 环境准备

使用独立测试浏览器上下文，在仓库运行 `python3 -m http.server 8080` 后打开 `http://localhost:8080`。若端口已有服务，先确认它对应的目录与版本；换端口时记录新 origin。

当前原型提供“重置本地进度”入口及确认框，可在独立测试环境使用。当前存档键为 `mellow-bean-idle-v1`；不清空整个浏览器存储。重置后记录状态，不把默认演示数值当作产品要求。

## fixture 契约

以下是逻辑契约，尚无自动加载器。执行前将变量绑定为具体值，并记录通过 UI 或计划批准的测试辅助方式如何建立；无法建立则 BLOCKED，不假定工具已存在。

| ID | 必须满足的状态 | 用途 |
| --- | --- | --- |
| FX-UPGRADE | 目标已解锁未满级；等级 L；规则价格 C；最小单位 u；余额 B；没有其他收支 | 升级交易与余额边界 |
| FX-SAVED | 一次合法操作已完成且已保存；记录应保存字段；刷新期间无其他业务变更 | 刷新恢复 |
| FX-OFFLINE | 已记录离开时刻及资产；离线时长 T；规则预期收益 E；可区分随后新收益 | 离线单次结算 |

若通过停业控制收入，必须验证待收、运输中现金也不会造成余额变化；不能只看到“打烊”就假定经济完全静止。若静止状态下禁止升级，需另建受控数据方案。

清理：关闭测试标签页，移除本轮临时控制/模拟，按环境约定重置测试存档；保留报告和证据。每个用例都独立准备，不能借用上一用例修改后的状态。
