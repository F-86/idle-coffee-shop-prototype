# Q1 fixture 与执行能力手册

所有用例使用 [候选 Q1](../../product/parameters.md)。这里给出可复用的逻辑状态，不假定现有 app.js 已提供加载器。状态准备失败不应删除用例或改成当前默认值。

## 两种准备路径

1. UI 路径：从独立新档，通过正常解锁、经营、暂停和管理到达目标状态，逐字段读取并记录。基线与产品配置一致时优先使用。
2. 测试适配路径：由独立测试入口载入 Q1 配置和初始状态，允许控制时间、供客和环境故障。必须记录入口、配置版本、输入与回读值；适配只准备前置状态，不能直接调用购买、发奖、存入等被测结果函数。

当前尚无确认可用的 Q1 入口。首次执行先做能力检查，无法达成精确前置时 BLOCKED/测试数据或工具。不要擅自改日常档、生产配置或操作系统时钟。实现测试入口属于后续开发任务，本轮文档不声称已经实现。

## 数据表

默认：A 店、营业暂停、B=200/P=0/M=0、未启用奖励加成、时间为 2026-09-19 12:00:00 Asia/Shanghai。用例显式前提覆盖默认。

| fixture | 前置状态与准备动作 | 回读检查 |
| --- | --- | --- |
| FX-FRESH | 隔离 origin 无本项目存档，使用 Q1 新档配置 | B200，一柜台一员工，美式可用，未完成引导 |
| FX-PRODUCTION | Q1 合法柜台/配方/员工；受控顾客与时间；按例要求设置在制阶段 | 柜台归属、选择、进度、独立顾客标识、B/P/M |
| FX-QUEUE | 生产暂停，清空队列，再安排1/2/3号顾客依序进入 | 入场顺序、所属柜台、人数 |
| FX-CASH | 无新生产，P按例设置，经理空车在金库，容量50 | 经理位置/容量、B/P/M；恢复运输但不恢复生产 |
| FX-UPGRADE | 目标L1已解锁，或例中锁定/满级；余额按参数 | 价格来自Q1独立表，余额及等级可精确读取 |
| FX-PROGRESSION | 目标配方/柜台的锁定状态及等级按例，暂停经营 | 选项、门槛、余额、等级 |
| FX-STAFF | 员工数/待命/归属按例；需要时两柜台已解锁 | 每名员工唯一ID与归属，人数不重复 |
| FX-MANAGEMENT | 四类经营属性均为Q1初始值，每组独立重置 | 升级前四项值及对应运行行为 |
| FX-ORDER | 新手作单、美式、耐心10秒、制作5秒、奖励15；连单按例 | 单号、剩余耐心/制作时间、连单和余额 |
| FX-BOOST | 速度1倍，无效果或冷却，美式充足顾客 | 效果结束/冷却结束时刻，杯价 |
| FX-REWARDS | 无新小费；目标进度、领取标记和罐余额按例 | B、罐、目标日期和领取状态 |
| FX-LOCATIONS | A/B按例锁定与等级；柜台、配方、员工、P分店记录 | 全局B、分店字段、经理带款来源 |
| FX-SAVED | 独立通过合法UI操作形成有差异的保存状态 | 对照SAVE-001字段清单逐项记账，并看到保存完成 |
| FX-STORAGE | 本项目存档副本和只限测试origin的故障注入 | 原始字节/摘要；加载后是否被覆盖 |
| FX-OFFLINE | 当前店美式L1，稳定r=2，无加速，离开时刻明确 | 关页前B/P/M、营业、时间；返回后区分新在线事件 |
| FX-UI | 丰富场景与已解锁弹窗；余额极值按例 | 视口、缩放、焦点、可访问名称和资产 |

FX-CASH 若不能单独推进经理，可以准备没有可生产员工的有效店铺，再通过 UI 开业；禁止靠打烊同时冻结经理却期待其运输。

## 时间与观察

精确边界通过局部测试时钟按目标时间推进并暂停观察；真实时间允许 ±0.25 秒采样误差，不放宽整数货币断言。真实 UI 无法分辨9秒/10秒边界时应改用受控时钟或BLOCKED，不猜测通过。

纯 Computer-Use 可做可见路径与布局测试；精确账目、版本迁移、存储失败、时钟回退需要额外读数或环境能力。每轮报告列出实际可用能力。UI 可读的精确详情优先；若使用只读状态快照，应公开字段和读数，且仍通过 UI 执行业务动作。

## 旧版迁移参考数据

候选测试逻辑旧档 v0 为：version=0、coins=200、counterLevel=2、unlockedRecipes=[americano,latte]。独立期望映射为 B=200、A店一号柜台等级2、两配方解锁，其他字段采用合法默认。连续两次加载不得再次赠送余额。

这不是现有应用存档schema。适配需把该逻辑数据转换成待支持旧版的真实字段，并提供独立映射清单；当前没有受支持旧版本映射时，该实例BLOCKED。未来版实例以version=999及可辨认余额构造，必须保留原始数据。

## 清理

每例结束移除局部时间、资源拦截和存储故障；关闭额外页并释放单写者；保存证据后重置测试档。清理失败写进报告，不污染下一例。
