# 首批行为规格

状态：draft。来源：经营游戏目标的建议细化，2026-09-19；尚未作为完整产品规格确认。以下规则用于展示需求到用例的链路，不从当前代码读取数值作为标准。

## REQ-ECO-001：升级交易

玩家可查看目标等级的升级价格 C；余额足够且满足解锁条件时，一次成功购买扣除 C 并提升一级。余额不足时等级和余额不变，并给出可理解的原因。连续输入不能产生负余额或无支付升级。

待明确：价格表、最小货币单位 u、显示与计算精度、等级上限、升级的具体效果。边界数据为 C-u、C、C+u。测试期间其他收入与支出必须被控制或完整计入。

## REQ-SAVE-001：刷新恢复

已完成且已保存的经营操作，在同一浏览器、同一 origin 刷新后可恢复；刷新本身不能重复购买或再次扣款。

待明确：持久化字段清单、保存完成的可观察信号和最长保存延迟、离线结算对余额的影响、旧存档兼容范围。动画中间态是否保存需单独定义。

## REQ-IDLE-001：离线收益单次结算

符合离线条件的时间区间按规则计算收益，同一时间区间不能因关闭提示、重复进入或刷新而重复获得收益。玩家能理解收益金额及去向。

待明确：计算公式、上限、最小时长、舍入、时间源、打烊语义、是否先进入待收现金、后台标签页与关闭页面的区别。

## 规格变更

确认规则时记录来源、日期和版本，更新关联用例。若新规则替代旧规则，记录替代理由及影响；过去运行报告保留当时规格版本，不追改历史结果。
