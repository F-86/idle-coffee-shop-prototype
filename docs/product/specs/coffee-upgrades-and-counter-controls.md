# 咖啡独立升级与柜台双入口

2026-10-05 UTC；COFFEE-2.0；REQ-3D-033 / TC-3D-023；基线 c6f7b95b3a7f66f2f2d0172ba925d3c7a96267ce。

## 已确认行为

- 墙上每种咖啡各有独立等级。面板突出等级、当前基础杯价与制作时长、下一级数值、升级费用及购买按钮；没有“供给柜台”操作或分配按钮，不增加重复介绍文案。
- 墙上实体咖啡牌同步显示配方当前等级、基础杯价与制作时长，只在该配方等级变化时重绘文字，避免升级后仍展示旧数字。
- 咖啡升级作用于所有选用该配方的柜台；另一种咖啡等级不变。配方等级和柜台等级互相独立，柜台和专长加成在升级后的咖啡基础值上应用。
- 柜台前脸左侧为咖啡选择器，右侧为柜台升级牌，是真实分离的实体拾取区域，分别打开选择和升级面板。柜体本身和两牌之间不能成为额外升级热区，仍正常遮挡后方物体。
- 选择面板只显示两种配方、在该柜台当前条件下的杯价/时长、当前选中态和必要的专长/下一杯提示。升级面板只显示该柜台当前配方、等级、当前→下级数据和升级费用。
- 升级只从金库可用余额扣款，金额整数分；不足、上限和不合法配方不购买。连续点击每次重新按最新等级报价，不重复使用旧费用。
- 制作中的杯子保留开始时的价格/时长快照。换配方、升咖啡或升柜台只影响之后开始制作的杯子，不重置队列、顾客或在制进度。
- 在线和离线使用同一核心及相同咖啡等级；80%无上限离线规则、现金搬运/入库时点、经理和柜台既有参数不变。
- 保存、读取、导入预览、导入、导入前备份和再导出都保留两种咖啡等级。旧有效存档与旧v1文件迁移为两种咖啡Lv1，旧在制杯不追改，迁移不凭空创造金币。

## 临时参数，不作平衡结论

用户明确先完善特性、以后再考虑数值增长。当前配置集中在核心，属于未校准的draft：咖啡Lv1–10；基础杯价按Lv1每级线性+8%，速度每级线性+2.5%（时长除以倍率）；浓缩首升1200分、拿铁2000分，后续费用倍率1.55，整数取整。满级不再扣款。
