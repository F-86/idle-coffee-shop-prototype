# 独立文件往返探针规格

范围：合成文件与系统文件选择器的可行性验证。生产游戏、本地游戏档、Mac 既有 4180 预览与发布配置不变。不是完整 iCloud 集成。

- **REQ-FILE-001 合成隔离：** 独立页面、独立构建，不导入游戏模块、读取游戏存储或真实存档。唯一允许的数据为 schemaVersion 1、UUID probeId、正整数 revision、UTC createdAt 与固定合成 payload 五字段。
- **REQ-FILE-002 用户选择：** 不在页面加载时申请权限。文件访问只由点击触发，针对单个选定文件；无目录枚举、后台扫描、持久句柄、OAuth 或 CloudKit 设置。
- **REQ-FILE-003 可用性退化：** 增强选择器必须按安全上下文与 API 存在检测。通用文件输入和下载为基础路线，当前 JSON 的 Web Share 文件能力仅作为可选路线。不把不可用功能伪装成可用。
- **REQ-FILE-004 输入边界：** 限定文件名、扩展名与 16 KiB 字节上限；严格 UTF-8 与 JSON/schema 验证。取消、拒绝和失败不替换已验证内容，允许重复选择同一文件。
- **REQ-FILE-005 新副本：** 不就地修改选中的原文件。每次导出新随机名称，增强保存拒绝变更名称或非空目标；revision 只在内存增加后另存副本。任何写入失败不报告成功。
- **REQ-FILE-006 可验证证据：** 显示当前内容来源、probeId、revision、原始字节 SHA-256 与本页导出基准比较。增强写入成功后逐字节读回。SHA-256 缺失必须说明，不报校验通过。
- **REQ-FILE-007 云同步边界：** 下载发起、分享返回、同机读回与第二设备可见区分记录。浏览器无法给出 iCloud 提供方或同步状态；跨设备到达必须由第二设备人工核对同一文件 ID/revision/完整 hash，不据本机成功推断。

范围外：真实游戏档导入、自动合并、冲突解决、原文件原地覆盖、全目录访问、账户登录、CloudKit 容器/权限、原生打包、新发布目标、Pages 更改。
