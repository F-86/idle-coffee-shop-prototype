# 简洁设置与首次开店引导

2026-10-05 UTC；SETTINGS-1.0；REQ-3D-034 / TC-3D-024。基线 cc995912cf0c22ffe72e679e08b54deb0e156f33。

## 玩家目标

设置只处理画面与存档。经营方法在第一次打开全新小店时，用短引导直接指向场景里的物件，不在设置中重复摆放说明或跳转入口。

## 行为要求

1. 设置只有两个一级入口：默认收起的“画面”和“小店存档”。画面摘要显示当前模式；展开后保持原四档选项、选中样式及独立偏好保存。移除“逛逛小店”“怎么玩”和独立“备份与恢复”菜单。
2. 本地保存状态、保存进度、生成/下载/分享文件、选择/预览/确认导入都在“小店存档”。健康状态不常驻恢复菜单；导入前的有效备份存在时，才保留对应的找回入口。
3. 保存失败、冲突、原始坏档、未来档、缺失、读取失败等需要处理时，设置的存档入口提示“进度需要处理”，存档页上方出现“保护这间小店”。原始档、有效当前副本、读取最新档/重试离线结算、确认新店按已有状态显示或禁用。不能把初始化占位店当成当前副本，不能因为普通读取或存储恢复而覆盖受保护的原文。
4. 同一个浏览器仅在仓库确认首次无存档且3D可用时展示一次引导。四步为：柜台左选咖啡、柜台右升级、咖啡墙升级配方、金库升级经理。每步用已有场景焦点突出对应实体，始终有“跳过引导”，最后为“开始营业”。
5. 引导是非模态短卡片，不暂停经营、不修改引擎暂停值、不接管全局键盘。打开操作面板、切到后台、处理离线结果或存档冻结时隐藏；通常返回后仍在原步骤。导入成功、接受显式读档替换或确认新店后结束旧引导。
6. 首次展示前写独立的浏览器标记，跳过和完成更新标记。刷新中断也不自动重播；已有存档（包括初始数值未发展档、旧版档、导入档）不强制触发。标记读取/写入失败时不自动开启引导，不影响正常游戏持久化。
7. 引导稳定步骤不重复改写礼貌播报区。关闭操作面板时不把焦点送回已隐藏/退役的引导按钮。

## 不变范围

不改变引擎、场景几何、画面预算、离线无上限80%规则、经济2、文件2、schema、金币与升级数值、文件协议或部署配置。不新增联网素材、依赖、自动云同步、教程重播菜单或新发布目标。数值平衡继续后置。

## 持久化边界

引导使用单独浏览器偏好 `mellow-bean:welcome-guide:v1`（shown / skipped / completed），不会写入游戏状态或导出文件。它与本地存档一样受清除浏览器数据影响；清除全部站点数据后是新的首次访问。偏好写入不可用时选择不弹出，而非用修改游戏存档来保证引导记忆。
