# 手动文件存档 v1

版本 PORTABLE-1.0；2026-10-05 UTC；REQ-3D-031 / TC-3D-021。代码基线 59c77998a95e23aa508a855e46b79561a4422f01（无上限80%离线经营及恢复保护）。这是手动文件交换，不是自动 iCloud / CloudKit 同步。

## 范围及入口

设置 → 手动文件存档。支持生成有效游戏进度 JSON、下载新副本、系统文件分享、文件选择导入、预览、确认替换、导入前备份导出。没有持久文件句柄、目录权限、后台写文件、账号接入、部署变化或货币合并。

生成文件之前先结算当前可确认的前台尾部，并成功保存。文件来自该次已保存的快照，不取散列计算完成后的变化状态。生成后的进度不会自动写入该文件。每次下载/分享使用含时间、修订号及随机 UUID 的新文件名，绝不主动覆盖已有文件。下载请求或分享完成不证明文件已落盘、更不证明 iCloud 或另一设备已收到。

保留设置中的原始档、当前副本恢复导出。旧恢复档没有完整文件协议，不能冒充可导入的新版存档。

## 文件协议

- 外层明确 format=mellow-bean-portable-save、formatVersion=1。
- payloadText 是完整的 JSON 字符串。SHA-256 对该字符串的精确 UTF-8 字节计算，包括其中的元数据、摘要和状态；外层排版不参与散列。
- 内容包含游戏 schema、经济版本、离线策略版本、saveId、revision、savedAt、exportedAt、派生进度摘要及完整游戏 state。v1 仅接受游戏 schema1 / 经济1 / 离线策略3；既有路线迁移仍须通过完整状态验证。
- 每次成功本地保存递增当前身份的 revision。老本地档第一次成功保存才获得身份与 revision1；文件导出要求成功保存，不在读取时偷偷迁移。
- 校验只检测内容是否与所附散列一致，不认证来源，不阻止持有人改写后重算散列，不是防作弊或跨设备一致性保证。
- 文件上限256 KiB；文件读取前检查 size，读后再检查实际UTF-8长度。拒绝错误格式、未知版本、无效/缺失校验码、不有限数字、不安全整数、无效关系与不守恒账本、伪造摘要及过深/过大结构。字符串只通过 textContent 显示。

## 导入、时间和冲突

1. 读取、解析、验证、摘要对比不会写游戏存档。合法预览开始前结算当前可确认前台尾部，然后在UI层冻结经营，不改state.paused。显示当前未存盘进度、本地最近保存时间、文件保存/导出时间、身份/修订/余额/等级/杯数/待收及在途现金。
2. 明确提示完整替换、不能合并金额、导出到导入间隔不发收益、关闭其他标签页。用户必须勾选关闭其他游戏窗口，再点击“备份并替换当前小店”。取消、关闭、Escape、新文件、存储事件、隐藏、页面离开、销毁会作废旧预览或异步结果。
3. 确认时创建唯一备份，包含原本地原始字符串（坏档也保留）和有效当前内存快照；不可读新店占位不作为有效当前副本。先写备份并逐字读取验证，再检查当前存档仍与预览基准一致，最后单次setItem替换并读回验证。备份写入/验证失败或检测到冲突就拒绝替换。
4. 替换写入开始后若结果无法验证，不能假称原档未变，也不自动回滚压过别的窗口；冻结并要求重新读取。已验证的备份仍可从本次页面导出。成功导入的最近备份指针随存档持久化；失败尝试的临时指针仅在当前页面保留，额外备份原始记录不会自动删除。
5. 导入创建全新的本地saveId，revision从1开始。业务资产完整替换，不叠加；不调用文件年代的离线结算。新离线锚点=max(确认时本地时间, 已验证原本地锚点)，不采用外来文件时间推动或冻结本地时钟。此后正常按本地80%规则结算。
6. 最近32个导入文件散列用于重复导入提示；它不是全局去重账本。再次明确导入允许回退到同一快照，仍不会发放导出后到导入的间隔收益。跨设备分支不会自动合并。
7. 备份不自动清除。配额不足则拒绝导入，请用户自行保留重要文件并管理浏览器数据。UI可把最近备份中的有效进度重新生成可导入文件，也可导出原始档。恢复导出使用新的saveId/revision1，避免把尚未存盘的状态冒充原身份下已保存的同一修订；原身份仍保存在备份记录内。

## 明确边界

localStorage没有跨调用事务/锁。上述字节比较和单次替换只是保守的乐观冲突检测，不是真正原子CAS；勾选关闭其他窗口不能技术性排除挂起旧页面的竞争。强跨标签页一致性需要以后统一迁移所有写入路径到事务型后端，或有充分限制的全写者锁协议，本版不声称做到。

预览期间不写暂停标记，正常取消/隐藏会重置可见时钟并保留进度；如果浏览器进程被强制终止，下一次启动仍从最后持久锚点按现有离线规则恢复。不能宣称强制终止时也精确保留预览暂停语义。

系统文件选择器/分享面板和iCloud到达需要实机独立验收。自动化内存故障注入和实际main.ts的模拟DOM执行不证明Safari文件面板、手机布局或双设备传播。
