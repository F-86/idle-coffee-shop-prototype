# 底部装修目录与真实拖拽

2026-10-05 UTC；LAYOUT-2.0；REQ-3D-036 / TC-3D-026。基线为家具闭环 LAYOUT-1.0，已验证树 6c9c2f51f84fde0ec5e24a97848fe4776620773b。

## 用户反馈与本轮解释

用户指出家具不能拖拽，希望装修时把全部家具、咖啡放入类似参考截图的底部横栏，并移除初始地毯。沿用当前暖色原创3D，只改变装修交互。底栏只在装修出现，不成为常驻经营HUD。

“咖啡”对应当前浓缩/拿铁各一块墙面菜单牌。每块有唯一配方身份，移动和收纳只改变牌子的摆放，不复制配方、不清除升级、不改变柜台可制作的咖啡；要使用墙面升级入口时可从底栏放回牌子。本轮没有新咖啡配方或经济调参。

## 验收行为

- REQ-3D-036.1：底部全宽横向目录包含全部、柜台、桌椅、咖啡、收纳分类。已有物件、收起物件和可添置物件有图形、名称、数量/等级/费用提示；现有功能柜台与桌椅均可从目录重新选择。
- REQ-3D-036.2：鼠标/触控指针可从目录拖出已有、收纳或待购物件；场景中的家具与咖啡牌也可直接拖动。拖过阈值后启动一次拖拽，不触发营业操作或重复添加。空白处拖动继续平移镜头；现有家具保留抓取偏移。
- REQ-3D-036.3：地面家具按整数网格吸附，墙面咖啡牌按合法墙位摆放；绿色预览表示可放，红色附具体原因。重叠、越界、动线阻塞、墙位不合法或余额不足均不能接受该次拖放。非法松手退回拖前草稿；底栏内/画布外松手取消当前移动。
- REQ-3D-036.4：拖拽只修改候选副本；合法松手只更新装修草稿，“完成布置”一次性提交并扣款。编辑中的自动保存不包含草稿。按住、重复松手、拖后click、重复完成不能重复购买。
- REQ-3D-036.5：pointercancel、丢失捕获、窗口失焦中止当前拖拽并释放捕获，保留此前草稿；Escape先取消当前拖动，再次Escape退出装修。隐藏/离页/冲突丢弃整个未提交装修，沿用原保护。多指次要输入不能接管主指针。
- REQ-3D-036.6：点击目录和移动/旋转/收起按钮保留无需拖动的操作路径。墙牌只允许左右墙位调整，不旋转；家具保留四方向旋转。触屏横向滑动物品栏，纵向拉出物件；横滑即使没有收到pointercancel，也不能在松手时变为添置。
- REQ-3D-036.7：新店、旧路线店和装修后店均删除地毯、经理路线涂层、装饰虚线及地面箭头；保留规则地板、入口实物和既有模拟动线。
- REQ-3D-036.8：布局版本2保存两块墙牌的身份、位置和收纳状态。布局1补默认墙牌后严格校验；现有在途角色、账本、配方等级、扩建与家具原样保持。经济与文件版本仍为3，未知未来布局、畸形牌数据或重复身份保护原始内容。旧文件原始字节/指纹保持，不把迁移后的正文冒充原文件。

## 可调但未变更的配置

柜台、桌椅、扩建费用/门槛和经营速度均不改。当前墙牌宽3.52，至少留0.2间隙；基础墙位整数x=-2..6，扩建另有12..14，避开装修牌与金库；默认x=0/5。墙牌高度2.7、墙面z=-3.45。墙位是布局约束，不是收费升级。
