# 双门小店、直接收款与暂停装修

状态：用户在 2026-10-05 明确要求的本轮行为；价格、容量、制作时间、升级曲线仍为原有 draft，不调平衡。

## REQ-3D-037：场景与收款

- 全屏轻 3D 主场景采用可见店外草地、铺地和道路的剖面式小店；默认镜头能看到建筑之外的区域。与用户参考图对齐的是空间组织和图形操作语言，不复制第三方素材。
- 新顾客从画面右侧入口进入，完成取杯、堂食或外带后从左侧出口离开。世界坐标负 X 对应画面右侧；基础店入口 `(-7,5)`，出口 `(10,6)→(11,6)`，扩建后出口移到 `(16,6)→(17,6)`。
- 柜台交出已付款咖啡的同一个逻辑边界即增加当前余额，只增加一次。坐下、喝完、起身、离店不再付款。
- 不再显示经理、手推车、现金堆、金库或经理升级入口。咖啡不挂在墙上，也不属于装修家具。配方等级和柜台配方仍完整保留。

## REQ-3D-038：营业状态与装修事务

- 常驻 HUD 有「暂停营业」按钮。点击后马上停止新客入店；店内客人正常取杯、喝完并离开，HUD 显示剩余人数。
- 装修必须先暂停营业。清场期间可打开家具面板看进度；没有客人和在制杯后才取得独立布局草稿。
- 完成布置只提交布局与一次购买支出；取消只丢弃草稿。两者都保持暂停营业。
- 点击「恢复营业」才重新接客。有装修草稿时该点击被拦住，并明确提示先完成或取消，不能静默应用或丢弃。
- 暂停是存档的一部分。刷新、切后台、导入、读档不会自动恢复；暂停快照的整个离线区间不制作、不收款。在线暂停后的清场收入是已有订单的正常付款。
- 存档保护、文件预览、离线计算等暂时冻结使用 UI 门禁，不冒充玩家的营业状态。保存失败仍保留原始档与安全恢复通道。

## REQ-3D-039：图标栏与有图目录

- 平时底部只有小型居中浮动图标栏：咖啡、背景、家具、招客。只提供能执行的功能。
- 咖啡入口可切换浓缩/拿铁升级卡；其中「管理营业柜台」提供带图的 44px 配方/升级触控替代入口。整体俯视构图中的实体柜台牌仍可点选，尺寸可能小于 44px。背景提供花园、露台、落日三种免费店外配色，只在当前设备保存，不影响经济或文件存档。
- 装修面板采用与其他游戏卡片一致的奶油色、圆角和描边，桌面最大宽 880px，四周留白，不铺满窗口。
- 每个咖啡、背景、家具以及购买候选使用原创本地 SVG 图片；不依赖外部请求。家具仍可拖出、直接拖动、旋转、收起/恢复，非法位置不提交，重复松手或完成不多扣钱。
- 暂不加入原料系统或空白占位按钮。有限库存会改变既有离线经营规则，补货方式需要另行决定。

## 存档迁移

- 经济版本 4、布局版本 3、手动文件版本 4。旧经理与墙牌字段仅作严格兼容信息保留，当前现金字段必须为零、墙牌保持收起。
- 旧柜台待收现金和经理携带现金一次性转到钱包，`totalEarned` 不重复增加；历史经理升级支出和等级作为历史记录保留，不退款。
- 旧在途顾客先沿原路线安全完成，迁移过渡期间不接新客，随后切换新双门路线。配方、等级、在制杯快照、拥有家具、消费记录保留。
- 仅当旧布局挡住新出口时，先收纳必要的阻挡家具；实在无法合法转换时将初始柜台放回安全位置、其他物件收纳。所有资产与等级保留，并显示持续提示，用户确认后才消除。
- 旧未结算区间沿用该区间记录的离线效率与时长规则；经济迁移后采用直接收款。新暂停档整段离线零收益。结算仍一次性、原子保存，取消或失败不能重复发钱。
