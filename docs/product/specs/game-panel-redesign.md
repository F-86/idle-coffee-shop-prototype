# 小店游戏面板 v1

> 柜台/咖啡部分已由[REQ-3D-033](coffee-upgrades-and-counter-controls.md)更新：咖啡独立升级，柜台选咖啡与升级分别开面板；下面保留本轮初版背景，设置/文件/离线要求继续适用。

2026-10-05 UTC；REQ-3D-032 / TC-3D-022；基线 f9f823e270d7934f6967860ad15b639e0f6af72d。

## 玩家目标

升级、设置和存档像游戏中的操作卡片，先看结果和主要操作，不让技术说明占满屏幕。离线回来只需要知道离开多久、到账多少钱。

## 表现要求

- 延续全屏暖色低多边形咖啡店；奶油色纸卡、咖啡色边框、绿色选中态、金色主要操作。新增装饰由 CSS/SVG 构成，不引入网络素材或依赖。
- 柜台：配方卡、当前与升级后的杯价/时间、升级价格、余额不足提示。回本和换配方说明折叠。
- 金库：可用余额、经理等级、当前/下级效率和升级价格。待收、运送明细折叠。
- 设置：本地保存状态、单次保存、小店存档入口、四档画面。选中状态同时以边框、勾选和 aria-pressed 表示。导航和帮助折叠；需要恢复时自动展开恢复操作。
- 文件：导出和导入分别为小卡片。下载/分享只在生成文件后出现。文件选择器保持可见原生 input，以 file-selector-button 美化，不使用异步 click 代替真实手势，不暗示拖放。
- 导入：默认只对比余额、杯数、柜台/经理等级和文件日期；UUID、修订、SHA-256、完整账本折叠。显示正在预览的文件名，避免原生 input 重置后让玩家误以为文件丢失。
- 确认前始终可见完整替换、不合并金币、不补文件导出至导入期间收益、先校验备份的后果；旧日期/重复文件分别警告。关闭其他标签页复选框及多窗口风险仍可见。备份容量/保留/清除数据和完整技术细节可展开读取。
- 离线结果只呈现实际离开时长（显示到整秒、向下取整）、实际已提交到金库的本次到账金额和继续营业。不把已生产但未送回的钱算成到账，不再向玩家展示有效经营秒数、台面/运送细分或迁移参数，也不重复弹出同金额 toast。
- 长结算仍有百分比和稍后再算，取消/保存失败/冲突恢复保持原保护。结果展示变化不调整任何存档、模拟时长或资产。

## 非目标

不改变经济数值、80%无上限离线规则、经理/顾客路线、场景性能预算、存档协议、CloudKit、部署配置或目标。旧用例中对应的表现断言由 TC-3D-022 替代，行为测试继续保留。

## 可访问和窄屏

原生 dialog、Escape/关闭/返回焦点和 inert 背景保持；输入有 label 和描述。预览完成后聚焦可读的预览区域，换面板重置滚动位置。触控操作最小44px，窄屏/横屏面板内部滚动。真实渲染、屏幕阅读器、Safari 文件面板必须独立实测；静态/模拟DOM检查不证明它们通过。
