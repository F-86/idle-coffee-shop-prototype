# 参数与测试数据契约

状态：draft；候选基线 v0.1；Q1 版本：`Q1-2026-09-19`。以下为独立设计的测试参考配置，目的是使边界、时间和账目可计算，绝不要求生产环境使用相同平衡数值。正式配置必须发布带版本的独立数值表，不能运行时从业务函数读取公式作为预期。

## Q1 可执行契约

Q1 的一个实例必须同时固定：版本号、时区、货币最小单位、初始状态、随机/到店序列、页面可见性、时间推进方式和观察字段。除非用例另有说明，本候选实例使用 `Asia/Shanghai`、整数日元、无随机数、A 店、营业暂停、`B=200/P=0/M=0`，并把顾客、在制杯和经理位置作为独立可读字段记录。

账务验收使用以下独立断言，而不是从实现函数反推期望：

- `A = B + P + M` 在每个采样点成立；搬运只改变 `P/M`，回库才改变 `B`，单杯收入只在“完成→同柜台队首取杯”之后增加一次。
- 所有货币字段以最小单位整数保存和显示；单杯收入、升级价格、离线收益分别按 Q1 表格的向下取整规则计算，不以展示四舍五入值代替底层读数。
- 营业暂停冻结生产、队列耐心、经理位置和 `M`；页面隐藏/恢复只结算一次明确的离线区间，不能把同一秒同时算在线和离线。
- 每个制作实例、顾客和现金转移都要能用稳定标识对应到一次事件；重复渲染、刷新或动画不能产生第二次交付或收入。
- 队列含服务中顾客，单柜台上限为 10；第 11 名顾客不改变已有队列、不产生收入，并沿右侧出口离店。

这些是候选版本的完整可执行规则，不表示用户已经确认 Q1 的商业平衡；正式评审仍需确认低等级默认容量、经理容量和生产价格表。

| --- | --- | --- |
| 货币最小单位 u | 1 | 整数；单次收益向下取整，内部/显示不得含糊 |
| 新档余额 | 200 | 1 号柜台、1 名咖啡师、美式已解锁 |
| 美式 | 杯价 10；制作 5 秒 | 同时最多制作 1 杯/柜台 |
| 拿铁 | 杯价 20；制作 8 秒 | 解锁价 100，门槛柜台等级 2 |
| 柜台升级 | L→L+1 价格 100L；上限 3 | 杯价系数 1+0.2(L-1)，制作时长不变 |
| 配方升级 | L→L+1 价格 100L；上限 3 | 杯价增加 2(L-1)，制作时长 max(1,初始时长-0.5(L-1)) |
| 经理 | 柜台→金库单程 2 秒；容量 50 | 空车到柜台也 2 秒；同一柜台余款下轮再收 |
| 队列 | 每柜台最多 10 人，含服务中顾客 | 满员时新客不入队，沿前场动线从右侧出口离店；具体低等级默认容量仍由经营配置决定 |

| 柜台解锁 | 每座 100 | 解锁后需分配员工才生产 |
| 四类经营升级 | 每次 100，上限 2 | 经理单程 2→1 秒；耐心 10→20 秒；容量 2→3；到店间隔 5→2.5 秒 |
| 手作 | 制作 5 秒；耐心 10 秒；奖励 15 | 连单第 3 单额外 5；超时清零连单 |
| 加速 | 2 倍生产速度，持续 15 秒 | 冷却 30 秒，自启动起算；不改变杯价 |
| 小费/每日目标 | 罐中 20；目标 3 人，奖励 30 | 领取后不能重复；自然日采用记录的本地时区 |
| 分店 | A 默认；B 门槛店铺等级 2、费用 100 | A 倍率 1，B 倍率 2；测试店铺等级可作为准备值 |
| 离线 | 最小 10 秒；上限 60 秒；倍率 0.5 | 参考稳定生产收入率 r；E=floor(r×min(T,60)×0.5)，T<10 或暂停时 E=0 |
| 保存 | 交易完成后 1 秒内 | 可观察保存信号；动画位置不保存，资产必须保存 |

收入公式：单杯=floor((配方基础价+2×(配方等级-1))×柜台系数×分店倍率)。禁止把杯价与每秒收益率混用。

Q1 测试可使用受控到店队列消除随机性；正常供客满足产能，队列测试使用明确数量的到店事件。如果未来加入随机性，提供独立种子并写入报告。`FX-QUEUE-10` 与 `FX-LONG-RUN` 的测试入口只在带 `test` 参数的独立浏览器 URL 中启用，生产 URL 不读取这些夹具，也不把夹具结果写入日常存档。

准备方法和入口字段见 [fixture 手册](../testing/shared/fixtures.md)。不能把当前默认演示存档误称 Q1；无法准备或回读精确字段时保留用例并报告 BLOCKED/测试数据。
