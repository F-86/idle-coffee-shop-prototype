# 设计决策清单

下列选择已在候选 v0.1 中给出具体提案，足以审阅和编写确定断言；尚无用户确认记录。确认后更新规格状态与版本，不需要复制测试用例。

| 决策 | 候选选择 | 影响 |
| --- | --- | --- |
| D01 经济模型 | 杯完成才产生收入，搬运不新增收入；整数货币 | 生产、经理、升级、数值展示 |
| D02 暂停 | 冻结生产、耐心、经理；允许升级 | 停业恢复及精确交易 fixture |
| D03 柜台互动 | 点击柜台前候客地毯立即完成当前在制杯并交付；柜台实体点击打开详情；自动经营继续；不保留订单弹窗/订单顺序 | 生产、顾客队列、待收反馈、三类入口隔离 |
| D04 分店资产 | 全局余额；柜台、员工分配与待收按店保存；仅当前店经营 | 切换、离线、保存 |
| D05 离线 | 自动一次性记入当前店待收；提示只展示 | 重复刷新、时间上限 |
| D06 恢复 | 旧版映射需明确；不支持的未来版只读保护；不静默覆盖 | 兼容、坏档、多标签 |
| D07 测试数值 | 使用 Q1；生产平衡表另行定义 | 价格表、解锁进度、长线体验 |
| D08 界面基线 | 横屏优先，竖屏可滑动，主要目标至少 44 CSS px | 移动、键盘和弹窗 |
| D09 逐杯账务 | 生产进度以在制杯快照推进；杯完成后只向同柜台队首交付一次，并只创建一笔待收现金事件 | 生产、队列、动画、回归账目 |
| D10 资金位置 | 现金账面拆为柜台待收 P、经理携款 M、金库余额 B；运输只移动现金，回库才增加 B；三者进入同一存档 | 经理运输、刷新、暂停、资产守恒 |
| D11 时间推进 | 只有一个应用时间推进器；营业关闭冻结它，页面隐藏/恢复用保存的最后时刻补齐一次，不能叠加后台收益与在线推进 | 暂停、后台、离线、恢复 |
| D12 本轮未定数值 | 沿用当前原型的柜台价格、制作时长和成本公式；经理容量、正式 Q1 数值和低等级默认队列容量仍是 draft；单柜台队列上限不再允许超过10人 | 实现连续性、测试报告限制 |
| D13 2.5D 动线 | 采用侧向 2.5D world：左入口→柜台前地毯→右出口；经理沿柜台与墙之间的后场通道轮巡，取杯/满位顾客均从右侧离店 | 场景层级、顾客事件、经理动画和浏览器验收 |

正式生产平衡、引导文案、美术目标图、历史存档版本清单尚待提供。相关测试按候选/Q1 可以定义，正式发布评估须换成确认版本。此列表记录业务选择，不阻止完善文档或独立开发。

本轮实现授权记录：2026-09-19，用户确认网页端、移动端优先、接入 Phaser，并要求完成上述逐杯交付、统一时间、存档守恒和 ATDD 验证；D12 所列数值仍按“沿用现状的实现假设”处理。

本轮动线补充：2026-09-20，用户明确提出侧向 2.5D 视角、柜台前地毯从柜台向外延伸、经理通道位于柜台与墙之间，以及左入口/右出口顾客流；单柜台最多 10 人，满位顾客不入队并从右侧出口离店。
