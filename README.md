# Mellow Bean · 放置咖啡店浏览器原型

这是一个参考放置经营类咖啡店玩法、但使用原创名称与视觉设计的纯前端原型。

## 运行

直接双击 index.html 即可打开。也可以在项目目录运行：

    python3 -m http.server 8080

然后访问 http://localhost:8080。

## 当前已实现

- 自动经营与每分钟收益
- 关闭页面后的离线收益
- 磨豆机、招牌配方、窗边座位、街角传单四类升级
- 晨间加速：15 秒双倍效率
- 小费零钱罐与手动领取
- 咖啡师招募
- 50 位客人的每日目标与奖励
- 营业中 / 打烊状态切换
- 浏览器本地存档与重置
- 桌面端与手机端响应式布局

## 文件结构

- index.html：页面结构与场景元素
- styles.css：界面、咖啡店场景和响应式样式
- app.js：经营循环、收益、升级、存档和交互逻辑

下一步可以接入真正的图片资源、音效、更多店铺和关卡，再将核心数值迁移到 Unity 或 Godot。
